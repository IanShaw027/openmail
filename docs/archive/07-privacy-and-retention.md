## 1. 原则（对外可展示）

OpenMail 为**单实例自托管**。角色：游客 · **注册用户** · 管理员。  
**游客不能搜索或浏览任何注册用户的邮件库**（硬性，无开关放开）。数据分轨：

| 模式 | 服务器是否存凭证 | 说明 |
|------|------------------|------|
| **仅浏览器缓存** | 否（取信时临时使用请求体中的凭证，默认不落库） | 本机可见；不能签发长期收码 API |
| **公开号池** | **是（加密）** | 实例内访问者可见；可收码 |
| **注册用户私有池** | **是（加密）+ owner** | 仅该用户（+管理员运维）；定时同步；「我的邮件」 |

| 类别 | 入库后是否长期保存 | 原因 |
|------|--------------------|------|
| 用户导入的账号凭证 | 是（直到删除） | 取信、收码 API |
| Cookie 会话 | 是（滚动续期） | 少登录、自动刷新 |
| OAuth refresh_token | 是（用户自备，非平台授权） | Graph 等 |
| 收码 API token | 是 | URL 映射账号 |
| 邮件正文 | 短时缓存 | 加速 |
| 访问日志 | 脱敏 | 禁止明文密钥 |

**无平台托管 OAuth/厂商授权**：所有密钥来自用户导入。

**正确表述示例**：

> 游客可将账号只保存在**本浏览器**，或放入**公开号池**（实例内他人可见，慎用）。  
> **开放注册**；注册时须同意[隐私政策](legal/privacy.zh.md)与[使用条款](legal/terms.zh.md)。  
> **注册并登录后**，邮箱与「我的邮件」仅归您的账户；他人（含游客）**不能**搜索您的邮件。  
> 凭证加密存储。Cookie 会话滚动续期。管理员管理实例与用户启停。  
> 本服务不代替厂商授权；令牌与密码由您自行提供。

## 2. Cookie 类特别说明

必须同时保存：

1. **email + password** — 会话失效时重新登录  
2. **cookies（Session）** — 日常取信复用  

仅存邮箱密码、每次全量登录：速度差、易风控，**不符合设计**。

会话策略（与 09 一致）：

- **以探测是否仍登录为准**，成功则滚动写回 cookies  
- **默认不做 6 小时硬过期丢弃**  
- 探测失败则自动密码重登（有密码时）  
- 可选配置绝对最大龄（默认关闭或远大于 6h）  

## 3. 收码 API 与留存

用户点击「API 取件」生成 URL 后：

- 服务器保存 `token → account_id`  
- 每次外部请求可能触发实时取信，并刷新 cookies / token  
- 因此 **API 功能开启 = 接受凭证留存**  

若用户删除收码 API 或删除账号：

- token 立即失效  
- 级联删除凭证与会话（删号时）  

## 4. 邮件缓存策略（默认建议）

| 项 | 默认 |
|----|------|
| TTL | 15–60 分钟 |
| 每夹最大封数 | 50 |
| HTML 最大字符 | 例如 120_000 |
| 用户清空 | 支持「清除邮件缓存」不影响凭证 |

收码 API 在缓存命中且含验证码时可直接返回（`cached: true`）；`refresh=1` 强制上游。

注册用户私有账号默认定时同步（约 **1 小时**）写入本人 MailIndex；详见 [12-trusted-pool-and-mail-sync.md](12-trusted-pool-and-mail-sync.md)。

## 6. 安全基线

- **实例模型**：入库账号列表对游客可见（公共号池）；这不是漏洞，须在 UI 标明  
- **管理密码**：保护全局配置、清库、删除服务端账号、无证明的 rotate/delete 收码接口  
- **凭证字段**：列表/API 默认不展示明文 password、refresh_token、cookies；at-rest **必须**加密  
- 传输 HTTPS；日志脱敏  
- HttpApi **必须** SSRF 防护（与 Provider 同交付）  
- 收码：**工程底线**（缓存、串行、最小间隔）；运营限流可后续  
- 备份与 DB 权限收紧  
- **游客搜邮**：API/页面一律拒绝；**无开关**

## 7. 运营方责任

若你将 OpenMail 提供给他人使用：

- 你是数据处理者，需自行合规  
- 应在部署页展示 [legal](legal/) 隐私与条款全文链接  
- 注册必须强制同意政策  
- 不得默认开启「把所有邮件长期归档」类功能  

## 8. 用户可执行的清除动作

| 动作 | 清除范围 |
|------|----------|
| 删除账号 | 凭证、cookies、邮件缓存、收码 token |
| 重置 API | 旧 URL 失效，凭证保留 |
| 清除会话 | 仅 cookies，保留 password |
| 清除邮件缓存 | 仅 MailCache |
| 卸载/删库 | 全部 |
