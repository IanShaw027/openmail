## L. 双存储数据流

```text
用户导入一行
     │
     ├─目标: 仅本浏览器 ──────────────────────────────┐
     │     localStorage/IndexedDB 写账号              │
     │     取信: POST 凭证 → 服务端代理 → 不落库      │
     │     收码 API: ✗ 需先入库                       │
     │                                                │
     └─目标: 保存到服务器（确认公开风险）─────────────┐
           服务端加密入库                              │
           取信: 读库 → Provider → 回写 cookies/token │
           收码: create-or-return → 唯一 URL           │
           浏览器缓存同步 url/token 字段               │
```

## O. 收码 API 权限与调用

```text
Web 用户点击「收码 API」
        │
        ▼
 账号已入库? ──否──► 提示先「保存到服务器」
        │是
        ▼
 POST create-or-return（游客可）
        │
        ├─ 无 token → 生成唯一 om_c_… → 返回 URL
        └─ 有 token → 返回同一 URL（不静默轮换）
        │
        ▼
 浏览器缓存写入 code_api_url
 用户复制 URL
        │
        ▼
 外部 GET|POST /api/v1/code/{token}
        │
        ├─ 短缓存有 code 且 refresh=0 → 直接返回
        └─ 否则 串行+最小间隔 → Provider.fetch → 解析码 → 返回
              format=text|json|nullx

rotate: 管理员 或 提交 current_token
delete: 仅管理员
```
