# 13 · UI / UX 与国际化（i18n）

> 产品界面原则与主路由地图。实现时对齐 **mail-public** 操作台信息架构，风格偏 **premium · modern · minimal**。  
> 法律全文见 [legal/](legal/)；角色与权限见 [09](09-decisions.md)、[12](12-trusted-pool-and-mail-sync.md)。

---

## 1. UX 原则

| 原则 | 说明 |
|------|------|
| **Premium / modern / minimal** | 干净层级、充足留白、克制装饰；状态与验证码用清晰字重与对比，避免花哨动效堆叠 |
| **少步骤、少点击** | 主路径：导入 → 点行取码 → 一键复制；收码 URL 一点生成/复制；避免多余向导 |
| **信息优先级** | ① 最新验证码 ② 邮箱 ③ 状态 ④ 凭证细节（编辑区，不挡主视线） |
| **角色可见即可用** | 游客不展示「我的邮件 / 同步 / 我的账号」入口；登录后自然出现，减少无效点击与误导 |
| **风险可预期** | 保存到服务器 / 公开号池前明确「实例内他人可见」；注册须勾选隐私与条款 |
| **失败可读** | 短句错误（会话失效、OAuth 异常、无凭证）；中英随界面语言 |

### 1.1 主路径目标操作次数

| 动作 | 目标 |
|------|------|
| 导入一批 | 粘贴 → 导入（1 次） |
| 看最新码 | 点行即展示 |
| 复制验证码 | **1 次点击** |
| 复制邮箱 | 1 次点击 |
| 复制收码 API URL | 1 次点击（生成或展示后） |
| 批量刷新 | 1 次点击 |
| 注册 | 填表 → 勾选政策 → 提交（无邀请码步骤） |

## 2. 国际化（i18n）

| 项 | 决议 |
|----|------|
| 语言 | **zh-CN** 与 **en**（首发必须） |
| 默认 | 可按浏览器 `Accept-Language`；用户可手动切换并记住 |
| 覆盖范围 | UI 文案、错误提示、页脚、注册/登录、**隐私政策与使用条款页面** |
| 法律页 | [privacy.zh.md](legal/privacy.zh.md) / [privacy.en.md](legal/privacy.en.md)、[terms.zh.md](legal/terms.zh.md) / [terms.en.md](legal/terms.en.md) |
| 切换 | 顶栏或页脚语言切换；**不**因换语言增加主路径步骤 |

实现建议：键值资源文件（如 `zh-CN.json` / `en.json`）；法律页可渲染对应 markdown 或静态路由。

## 3. 主路由地图

```text
公开 / 游客可访问
  /                     主操作台（账号取件台）
  /login                登录
  /register             开放注册（须勾选隐私 + 条款）
  /legal/privacy        隐私政策（随语言 zh/en）
  /legal/terms          使用条款（随语言 zh/en）

仅注册用户（未登录 → 引导 /login）
  /me                   可选：个人总览或重定向到 /me/mails
  /me/mails             我的邮件（搜索；游客禁止）
  /me/accounts          我的邮箱账号（私有池 CRUD）
  /me/sync              同步状态 / 手动同步

管理员
  /admin                管理入口
  /admin/login          管理密码登录（可与 /admin 合并）
  /admin/settings       全局代理、sid 池、同步间隔等
  /admin/users          用户列表、启停（无审批队列）

API（摘要，详见 05 / 12）
  /api/v1/code/{token}  收码 GET|POST
  /api/me/mails/search  仅登录用户 · 本人 MailIndex
```

### 3.1 导航可见性

| 入口 | 游客 | 注册用户 | 管理员 |
|------|------|----------|--------|
| 账号取件台 `/` | ✅ | ✅ | ✅ |
| 登录 / 注册 | ✅ | 登录后隐藏或改「账户」 | ✅ |
| 我的邮件 / 我的账号 / 同步 | ❌ 不展示 | ✅ | 若兼用户则 ✅ |
| 隐私 / 条款 | ✅ 页脚 | ✅ | ✅ |
| 管理 | 入口可选展示 | 可选 | ✅ |

游客访问 `/me/*` 或搜邮 API → **401/403** 或跳转登录；**无**「对游客开放搜邮」开关。

## 4. 关键界面要点

### 4.1 主操作台 `/`

- 侧栏：品牌、统计、导入、筛选、导出  
- 主区：账号列表 + 快捷复制  
- 下区：邮件列表 + 详情 + **验证码条**（最大可点复制）  
- 存储列区分 💻 本机 / 🌐 入库（公开号池）  
- 顶栏：语言、登录/注册或用户菜单  

### 4.2 注册 `/register`

```text
用户名 / 密码 / 确认密码
☐ 我已阅读并同意《隐私政策》与《使用条款》（链接可点开）
[ 注册 ]   ← 未勾选 disabled

无邀请码字段 · 无「等待审批」状态文案
```

### 4.3 登录 `/login`

```text
用户名 · 密码 · [登录]
还没有账号？[注册]   ← 开放注册，一步到达
```

### 4.4 法律页 `/legal/*`

- 全文可读、可打印风格；顶栏返回站点  
- 中英版本随当前语言；页内可链到另一语言  
- 不塞广告、不强制二次弹窗打断阅读  

### 4.5 我的邮件 `/me/mails`

- 多字段：发件人 / 收件人 / 主题 / 正文 / 时间 / 账号  
- 结果行：时间、我的邮箱、主题、验证码一键复制  
- 与主台验证码交互一致，避免两套习惯

## 5. 视觉与组件基调（指导，非锁死栈）

| 项 | 建议 |
|----|------|
| 布局 | 清晰栅格；主台三区（侧 / 表 / 邮）可折叠，默认一屏完成主路径 |
| 密度 | 列表紧凑但行高可点；移动端优先验证码与主按钮 |
| 色彩 | 中性底 + 单一强调色；成功/错误语义色克制使用 |
| 字体 | 系统 UI 或单一无衬线；验证码可用等宽加大 |
| 反馈 | Toast 短句；危险操作一次确认即可，避免连环模态 |
| 无障碍 | 对比度达标；按钮可聚焦；关键操作有文案不仅有图标 |

技术栈 **不定死**（见 09）；UI 实现时以上原则优先于具体组件库。

## 6. 文案与合规挂载点

| 位置 | 内容 |
|------|------|
| 全局页脚 | 隐私 · 条款 · 语言 · 公开号池一句风险提示 |
| 注册 | 强制勾选 + 链到 `/legal/privacy`、`/legal/terms` |
| 导入选「保存到服务器」 | 确认：实例内他人可见 |
| 首次收码 API | 持有链接可取码；可不再提示 |
| 游客点「我的邮件」类深链 | 引导登录，不展示空壳搜邮 |
