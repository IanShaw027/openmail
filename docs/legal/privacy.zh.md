# OpenMail 隐私政策

> 适用对象：本 OpenMail **单实例自托管** 部署的访问者与运营方。  
> 最后更新：2026-08-02  
> 英文版：[privacy.en.md](privacy.en.md) · 使用条款：[terms.zh.md](terms.zh.md)

---

## 1. 概述

OpenMail 是**本地优先（local-first）** 的多源邮箱取件控制台：

- **主路径**：邮箱凭证、2FA、邮件缓存加密保存在**您的浏览器金库**中（vault 密码 / 恢复密钥不出浏览器）。  
- **服务端**：作为自托管代理，短暂使用请求中的凭证访问上游邮箱 API；可选保存**客户端密封**的云端备份（运营方无法在无 vault 密钥时解密）。  
- **非 SaaS**：项目方不统一运营公有云；**数据处理者**通常是部署该实例的个人或组织（「运营方」）。

使用本服务即表示您理解并接受本政策。

## 2. 我们处理哪些数据

### 2.1 浏览器本地（默认）

| 类别 | 说明 |
|------|------|
| 金库密文 | 账号、2FA、mailCache 等 AES-GCM 密文（localStorage） |
| 设备密钥 | 用于 vault 设备 HMAC 的本地秘密（注册后服务端仅存哈希） |
| UI 偏好 | 语言、布局、筛选等非敏感配置 |

### 2.2 服务端可能处理

| 类别 | 说明 |
|------|------|
| 代理取件/发信 | 请求体中的凭证**临时**用于 Graph / IMAP / SMTP / HttpApi；默认不落库 |
| 客户端密封行 | 可选云端备份 blob；服务端不可解密 |
| 设备注册 | `vk_*` 设备 id + 密钥哈希，用于 HMAC 鉴权 |
| 遗留 code-API | 若数据库中仍有历史 token，可按 token 取码 |
| 日志 | 尽量脱敏；**禁止**明文记录 password、refresh_token、cookies 全文 |

### 2.3 我们不做什么

- **不**提供多用户注册 / 管理后台登录（产品已移除）。  
- **不**代用户向微软/Google 等发起平台 OAuth 授权页。  
- **不**将邮件用于广告、画像或二次售卖。  
- **不**承诺零知识代理：代理取件时进程内存中会短暂持有凭证。

---

## 3. 数据归属与控制

- 浏览器金库数据由**您**控制；忘记密码且丢失恢复密钥将**无法恢复**密文。  
- 运营方控制服务器密钥（`OPENMAIL_MASTER_KEY`）、数据库、代理出口与访问日志。  
- 客户端密封云端行：运营方有存储与删除能力，但无 vault 密钥则无法读取明文凭证。

---

## 4. 保留与删除

| 数据 | 建议 |
|------|------|
| 浏览器密文 | 用户可清空站点数据 / 锁定并销毁金库相关键 |
| 代理请求 | 不作为长期凭证存储；会话级内存 |
| 云端密封行 | 用户可在控制台删除；运营方可清库 |
| 设备注册 | 轮换 master key 或清注册表后需重新注册 |

控制台提供保留天数设置，用于**本地**邮件缓存裁剪。

---

## 5. 安全措施（概要）

- 浏览器：PBKDF2 + AES-GCM；锁定时清除内存中的密钥与明文。  
- 传输：建议 HTTPS；设备 HMAC 保护云端与代理接口。  
- 出站：SSRF 检查与 DNS pin（尽力）。  
- 内容：邮件 HTML 经白名单消毒后展示。

详见项目 [SECURITY.md](../../SECURITY.md)。

## 6. 第三方与出站

取件会连接您配置的邮箱服务商与可选 HTTP/SOCKS 代理（含 WARP 池）。合规责任由运营方与使用者共同承担。

## 7. 儿童与敏感用途

本工具面向技术用户自托管；请勿用于违法获取他人邮箱。未成年人使用须遵守当地法律与监护人要求。
