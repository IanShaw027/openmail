## 1. Service description

OpenMail is an open-source, **local-first** multi-source mailbox console (browser vault + self-hosted FastAPI proxy). Operators deploy instances; source code is provided under MIT and does **not** create a hosted service obligation by the authors.

## 2. Acceptable use

You agree to:

- Use only mailboxes and credentials you are authorized to access.  
- Comply with mail providers, proxy vendors, and applicable law.  
- Not use the software for spam, unauthorized access, harassment, or unlawful surveillance.  
- Not bypass rate limits, device HMAC, or operator access controls.

## 3. Credentials and risk

- You control the vault password and recovery key; loss may make data unrecoverable.  
- Proxy fetch **briefly** processes secrets in the server process; do not deploy on untrusted hosts.  
- Client sealing does not transfer legality of imported content.
